# Grid Initial Launch Strategy

## Launch Platforms

**Primary channels for first release:**
- **Reddit** (r/Hytale, r/HytaleMods if exists)
- **Discord** (Hytale official modding channels)

**Post-launch adoption:**
- Organic growth through GitHub (Issues, Discussions)
- Platform/foundation mod approach - other modders discover and build on it

---

## Pre-Launch Preparation

**Week -1:**
- Prepare teaser content (short video/GIF of 4-state logic in action)
- Draft announcement posts for Reddit and Discord
- Finalize project README and documentation
- Take high-quality screenshots/GIFs for posts

---

## Launch Day (Release Day)

### 1. Publish GitHub Release
- Follow the release process in RELEASE-MANAGEMENT.md
- Ensure README is polished (screenshots, installation, feature list)

### 2. Reddit Announcement
**r/Hytale:**
- Keep it brief, focus on what makes Grid unique
- Lead with GIF/screenshot
- Title example: "Grid: 4-State Digital Logic for Hytale Modding"
- Post timing: Aim for peak hours (early afternoon US time)

**r/HytaleMods** (if exists):
- More detailed technical post
- Include API examples for other modders
- Explain the platform/foundation approach

**Posting Style:**
- GIFs > Screenshots > Text
- "Show, don't tell" — lead with a cool build, explain after
- Be active in comments — answer questions quickly

### 3. Discord Announcement
**Hytale Official Discord:**
- Share in modding channels (respect server rules)
- Brief announcement with link to GitHub
- Respond to questions/feedback

---

## Week +1 Follow-Up

- Monitor Reddit/Discord feedback
- Respond to questions and bug reports
- Create a "Getting Started" guide if needed
- Share example: "Here's a working clock circuit in Grid"

---

## Positioning

**Key messaging:**
- Grid is a **platform/foundation mod** for tech mods and modpacks
- 4-state logic system (not binary)
- Clean API for other modders to build on
- Open source, actively maintained

**Target audience:**
- Hytale modders who want digital logic in their mods
- Players interested in technical/redstone-like gameplay
- Modpack creators looking for a power/logic foundation

---

## Success Metrics (Initial)

- GitHub stars as interest indicator
- Downloads per release
- Community questions/issues (shows people are using it)
- Other modders building on Grid (integration/dependencies)

**Realistic first milestones:**
- 50-100 stars — Small interested community
- 200-500 downloads — Solid proof of concept
- First issue from external user — People are actually trying it
- First mod dependency — Another mod builds on Grid

---

## What NOT to Do

- Don't promise release dates
- Don't spam subreddits or Discord servers
- Don't engage with trolls or drama
- Don't overhype — let the mod speak for itself
- All posts require AK approval before publishing
